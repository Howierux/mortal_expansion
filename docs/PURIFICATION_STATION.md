# Purification Station reagents

The Grave Moss slot also accepts Holy Salt. Either reagent is consumed one-for-one with Raw Ectoplasm when purification starts, producing one Pure Ectoplasm after 60 ticks with 1,000 mB water and 100,000 FE. Manual insertion, shift-click and automation use the same acceptance rule. Invalid items and a blocked output cannot start purification or consume ingredients.

Accepted reagents are generated through the mortal_expansion:purification_reagents item tag, initially Grave Moss and Holy Salt. Data packs may extend that tag. Existing slot indices, stored inventory data and processing costs remain compatible with saves; no migration is needed.

# Mortal Integrations

Mortal Integrations is an independent addon mod with its own `mortal_integrations` ID, Gradle project, and distributable JAR. Its first integration is JEI for Minecraft 1.21.1 / NeoForge. Source lives at [addons/mortal-integrations](../addons/mortal-integrations/README.md) in this repository; it does not add JEI dependencies to the base mod.

The addon provides Ectchantment Machine, Purification Station and heated-cauldron reference categories, furnace catalysts, book tier subtypes and a spectral Secrets of the Dead notice on secret crafting/smithing recipes. All recipes remain visible as requested. The notice explains that revelation is required; it does not grant knowledge or bypass server crafting restrictions.

Install on the client alongside Mortal Expansion, JEI and their dependencies. No local playtest installation is updated automatically. See the addon README for build commands, dependency pins, supported scope, verification and visual-playtest limits.

# Tapping Haunt audio

The HIT/tapping Haunt effect now plays the user-supplied Warframe Rell "Rap tap tap" clip rather than the single vanilla stone-step sound. The custom `mortal_expansion:haunt_tapping` sound is sent only to the affected player, positioned two blocks behind them, on the Ambient sound channel at volume 0.8 and original pitch 1.0. Other footstep effects remain unchanged. Existing personal-tier eligibility, protections, gear-prevention notifications, effect hints and cooldowns apply.

The supplied MP3 was converted to mono Ogg Vorbis at 48 kHz for Minecraft's positional audio. Duration is 5.3 seconds; no extra speech was generated or substituted. The subtitle is "Rap... tap... tap...". The sound definition is generated by a Java NeoForge sound provider. Server/client sound registry keys are stable; no saved-data changes or custom packets are introduced.

Operator testing: `/mortalexpansion haunt effect @s hit`. Remove full protective garb and leave any active blessing/ward if testing audible playback. Use Minecraft's Ambient sound volume and subtitles settings normally.

The clip remains a third-party Digital Extremes/Warframe asset. See [Third-party audio](THIRD_PARTY_AUDIO.md) for provenance and policy reference. Resource packs can override this sound asset using Minecraft's normal resource system.

Migration checks: sound registry registration, generated sound definition, native single-player sound packet and Ogg mono decoding. Build, data generation and existing Haunt tests validate registration/playback dispatch; actual audibility and volume balance remain client playtest checks.

# Audio provenance

Updated 2026-10-16. The tapping Haunt effect references vanilla Minecraft wood impact samples through Minecraft's resource system. These assets are supplied by the game and are not copied into or redistributed in the mod JAR.

The previously supplied Warframe Rell recording has been removed from the current source and packaged resources. Historical commits and dated notes still record its earlier use; this change does not rewrite repository history or revoke copies already downloaded. No Warframe audio is included in new builds from this revision.

See [tapping audio](TAPPING_AUDIO.md) for behavior and the stable resource-pack sound event.
